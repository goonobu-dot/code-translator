# X投稿用ドラフト(長文・有料会員向け)

---

【OSS公開】コードが読めなくても、AIの書いたコードを「読める・確認できる」ツールを作りました

AIにアプリを作らせる人が一気に増えました。私もその一人です。でも、ずっと引っかかっていたことがあります。

「AIが書いたコード、自分では1行も読めない。このまま公開していいの?」

これは気のせいではなくて、実測データがあります。AIが生成したコードの約45%に既知のセキュリティ問題が含まれる、という調査結果(Veracode)。動くものは作れる。でも「安全かどうかを発注者が確認する手段」が、世の中にほぼ存在しない。

だから作りました。「コード通訳」。今日からオープンソースです。

▼ 何をするツールか

コードを「数行の意味のまとまり」ごとに区切って、左に日本語の説明、右に実際のコードを並べます。英語の本の対訳版と同じ形式です。あなたがやることは、説明を読んで3つのボタンのどれかを押すだけ。

✓ 問題ない(意図どおり)
✗ おかしい(そんな動き頼んでない)
? わからない

正解を当てるテストではありません。「あなたが望んだ通りか」を答えるだけです。

▼ 機能ぜんぶ紹介

・ファイル名のボタンを押すと、そのコードが翻訳済みで即表示(翻訳は事前に済んでいるので待ち時間ゼロ)
・お金・個人情報・削除に触れる危ない箇所には⚠マーク。「次の注意箇所へ」ボタンで⚠だけを順番に巡回できる
・コードの行にマウスを乗せると、その1行の訳が出る。ifやconstなどの単語に触れると意味のヒントも
・気になることは「コメントを書く」に普通の言葉で。「ここは確認画面を挟んでほしい」とか
・✗とコメントはファイルに保存され、AI(Claude Code)に「たまった指摘を直して」と言うだけでまとめて修正される
・一番下に「公開してよいか」の判定。全部✓になるまで絶対に緑にならない
・コードが変わると回答は自動で無効化。「昔のコードへの承認」が使い回される事故を防ぐ
・学習モード: 説明を隠して「この数行は何をしている?」→自分で予想→クリックで答え合わせ。単語カード方式で、使うほどコードが読めるようになる
・AIが開発中なら、編集のたびに差分の対訳が自動で付いてくる「翻訳モード」も
・Gitの履歴を日本語のタイムラインにする「作業履歴の翻訳」で、後からの振り返りもできる

▼ 設計で一番こだわったこと

このツールは「安全です」とは絶対に言いません。

読めていないファイルは「未読」と赤で表示する。AIの説明は間違いうるから、必ず実物のコードを隣に置く。未回答・✗・?が残る限り判定は緑にしない。売っているのは「安心」ではなく、「あなたが何を確認して、何が未確認か」の正直な記録です。

きれいなレポートほど人を油断させる。だから「見せかけの安心」を作らない設計にしました。

▼ 使い方は3ステップ

1. git clone(READMEに手順あり)
2. code-translate 自分のアプリ --open
3. ブラウザが勝手に開く。次からはフォルダに自動生成される「コード通訳を開く.command」をダブルクリックするだけ

Claude Codeユーザーなら、チャットに「コードを翻訳して」と打つだけでも動きます。費用は翻訳の生成時のみ(小さいアプリで1回数十円)。コードに変更がなければ何度でも無料。

▼ こんな人に

・AIでアプリを作っているけど、中身がブラックボックスで不安な人
・外注やAIの納品物を「発注者として」確認したい人
・コードを読めるようになりたいけど、教材より「自分のアプリ」で学びたい人
